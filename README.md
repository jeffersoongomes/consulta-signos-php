# Consulta de Signos Zodiacais em PHP e XML

Aplicação web desenvolvida para consultar as características dos signos do zodíaco a partir de uma data de nascimento.

## 🛠️ Tecnologias Utilizadas
- **PHP:** Processamento e lógica de manipulação do XML.
- **XML:** Estrutura e armazenamento dos dados dos signos.
- **Bootstrap / HTML / CSS:** Interface responsiva e estilização.

## 📂 Como executar o projeto
1. Copie os arquivos para a pasta `htdocs` no XAMPP.
2. Inicie o servidor Apache no painel do XAMPP.
3. Acesse `http://localhost/Project/index.php` no navegador.
